## About

Java/Spring 기반 백엔드와 React/Next.js 화면 개발을 함께 다루는 개발자 강건입니다.

AI-OCR 운영 웹, 문서 처리 시스템 연동 API, LLM 기반 서비스 프로토타입을 경험하며 **AI 결과를 사람이 검토하고 신뢰할 수 있는 업무 흐름으로 연결하는 개발**에 관심을 두고 있습니다.

기능을 만드는 데서 끝내지 않고, 사용자가 어떤 화면에서 결과를 확인하고 어떤 데이터가 다음 업무로 이어지는지 함께 고민합니다.

현재는 금융, 공공, 업무 자동화 영역에서 **문서, 데이터, 사용자 검증 흐름을 연결하는 백엔드/AX 개발**을 중심으로 성장하고 있습니다.

## What I Focus On

- **Backend API**: Java, Spring Boot 기반 REST API 설계와 외부 시스템 연동
- **AI Workflow**: AI-OCR, LLM API, FastAPI를 활용한 AI 기능의 서비스 흐름 연결
- **Front-End**: React, Next.js, JSP, JavaScript 기반 운영 화면과 사용자 검증 화면 구현

- **Collaboration**: Git/GitLab 기반 협업, 요구사항 정리, 화면 흐름 설계, 운영 환경 이슈 추적

## Featured Work

### AI-OCR Operations Web & System Integration

Enterprise document processing project focused on OCR result review, privacy masking, similarity inspection, PDF viewer integration, and document workflow APIs.

- Built operation screens for OCR data, personal information extraction, de-identification results, image similarity checks, statistics, reports, and Excel download.
- Integrated PDF.js viewer with highlighted text/image duplication evidence so reviewers can compare AI results with the original document.
- Developed Java/Spring Boot APIs for document download and replacement flow between business management, document storage, and AI-OCR systems.
- Worked across development, staging, and production-like environments while tracking external integration issues.

### News Big Data Hackathon

[Project Page](https://9un.site/projects/news-bigdata-hackathon) · [Repository](https://github.com/Gun-E/cronews)

Led service planning and web development for a news quiz service that helps users encounter news keywords through a crossword-style game experience.

- Connected news data and LLM-based generation flow to create keywords, explanations, difficulty, summaries, and related article paths.
- Implemented the quiz board and article exploration flow with Spring Boot, FastAPI, Next.js, React, AWS, and Docker.
- Advanced to the final round among roughly 120 teams and won the top excellence award.

### Customer Experience AI Service

[Portfolio](https://9un.site) · [Repository](https://github.com/Gun-E/modii)

Planned and implemented an AI conversation service that proposes appliance usage based on user schedule, hobbies, and owned device information.

- Analyzed customer behavior data to define pain points around unused smart appliance features.
- Connected Python/FastAPI AI logic with Java/Spring backend and React UI so user context could affect the next response.
- Won the top excellence award in the LG Electronics DX School customer experience project.
